CappyCad — a simple 3D modeler for schools (offline)
====================================================

WHICH FILE DO I NEED?
  Windows 10/11 ............ CappyCad-*-Windows-Setup.exe (installer) or *-Windows-x64-portable.zip (no install)
  macOS (Apple M1–M4) ...... CappyCad-*-macOS-arm64.zip
  macOS (Intel) ............ CappyCad-*-macOS-x64.zip
  Ubuntu / Debian / Mint ... CappyCad-*-Debian-Ubuntu-amd64.deb   ->  sudo apt install ./CappyCad-*.deb
  Arch / Manjaro ........... CappyCad-*-Arch-x86_64.pkg.tar.xz    ->  sudo pacman -U CappyCad-*.pkg.tar.xz
  Other Linux .............. CappyCad-*-Linux-x86_64.AppImage (chmod +x, then run) or .tar.gz
  Any browser (no install) . CappyCad-*-Web.zip (index.html — open from disk or a web server)
  SHA256SUMS.txt ........... checksums of the downloads

NOTES
  Windows: SmartScreen may warn (no paid code signature): "More info" -> "Run anyway".
  macOS: unzip, move CappyCad to Applications, then right-click -> Open the first time.
    If it is still blocked: System Settings -> Privacy & Security -> "Open Anyway",
    or in Terminal:  xattr -cr /Applications/CappyCad.app

Lessons: 10 example projects and 8 step-by-step exercises whose steps tick off automatically.
There is also a banana for scale (about 18 cm).
Cappy, the capybara in the bottom-left corner, gives hints while you work and tips when clicked
(hints can be muted in the speech bubble).
The interface language (Polish / English) is switched with the PL | EN toggle in the top-right corner,
the light/dark theme with the sun/moon button (or the T key). Press F1 for help and shortcuts.
CappyCad works fully offline: no accounts, no data sent anywhere.
